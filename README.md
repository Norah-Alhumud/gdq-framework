# Geospatial Data Quality & Governance Framework

Rule-based quality assessment of OpenStreetMap buildings, roads and points of interest for the Dammam–Khobar urban area (206.4 km²).

| File | What it is |
| --- | --- |
| `index.html` | Interactive dashboard (opens as the project website) |
| `GDQ_Report.pdf` | Technical report: framework, results, maps and recommendations |
| `GDQ_QC_Workflow.ipynb` | ArcPy notebook that reproduces every check from the raw OSM extract |

**Key results:** 110,818 features assessed · 15 rules across 6 quality dimensions · 8 of 13 compliance targets met · 63.3% of major roads named (project target 95%).

Targets are set by this project for assessment; they are not official OSM or regulatory standards.
